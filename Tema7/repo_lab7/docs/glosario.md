# Glosario único (v1.1)

| Término | Definición | Desde |
|---|---|---|
| Cajero | Actor que registra pedidos y cobros (reemplaza «Recepcionista», H1) | v1.0 |
| Pedido | Solicitud de productos de un cliente, con ciclo de vida de estados | v1.0 |
| Comprobante | Documento emitido por un pedido cobrado | v1.0 |
| **Medio de pago** | Forma de pago de un pedido: Efectivo, Tarjeta, Yape o Plin | v1.1 (CR-001) |
| **Billetera digital** | Aplicación de pago móvil (Yape, Plin) usada como medio de pago | v1.1 (CR-001) |
| **Número de operación** | Código único que identifica una transacción de billetera | v1.1 (CR-001) |
| **Simulador de billetera** | Componente de pruebas que imita la confirmación de la billetera (mitiga R5) | v1.1 (CR-001) |
